# v0.12.0 Release Notes

**Release Date:** 2026-06-28

## Highlights

- **Developer Productivity Frameworks** - Add SPACE, AI-DORA, and AI-SPACE framework support
- **PRISM Ecosystem Updates** - Updated to latest prism-core, prism-capability, and prism-roadmap

## Added

### Developer Productivity Frameworks

New framework constants for measuring developer productivity and AI-assisted development:

```go
import prism "github.com/grokify/prism-maturity"

// Developer Productivity Frameworks
prism.FrameworkSPACE   // Satisfaction, Performance, Activity, Communication, Efficiency
prism.FrameworkAIDORA  // AI-Modified DORA metrics
prism.FrameworkAISPACE // AI-Modified SPACE framework
```

### Framework Helper Functions

New functions for querying framework categories:

```go
// Get operations-focused frameworks (DORA, SRE, AI-DORA)
ops := prism.OperationsFrameworks()

// Get developer productivity frameworks (SPACE, AI-SPACE)
devprod := prism.DeveloperProductivityFrameworks()

// Get AI-enhanced frameworks (NIST AI RMF, AI-DORA, AI-SPACE)
ai := prism.AIFrameworks()
```
